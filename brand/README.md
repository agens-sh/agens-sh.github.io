# agens mark

Lowercase Atkinson Hyperlegible Bold `a` (Braille Institute, SIL Open Font License) converted to paths, centered in a circular arc. The arc is a constant-radius ring, open 28° on the right so it reads as @. No webfont at render time.

| File | |
|---|---|
| `agens-loud.svg` | Fluorescent `#FF4D00` on a near-black rounded tile |
| `agens-dark.svg` | Restrained light mark, transparent, for dark backgrounds |
| `agens-light.svg` | Restrained dark mark, transparent, for light backgrounds |
| `agens-favicon.svg` | Enclosed `a` only, `#FF4D00` on transparent, 32×32 (tab icon) |
| `agens-favicon-dark.svg` | Same light mark, 32×32, transparent |
| `agens-favicon-light.svg` | Same dark mark, 32×32, transparent |
| `agens-wordmark.svg` | Mark plus `agens`, for light backgrounds |
| `agens-wordmark-dark.svg` | Mark plus `agens`, for dark backgrounds |
| `agens-avatar.svg` | Square org picture, full-bleed near-black, circle-safe |
| `agens-og.svg` | Social card, 1280×640 |

Motion, not built: the outer arc can loop while waiting, or the `a` can rotate into the pocket.
